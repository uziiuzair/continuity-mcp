Privacy Policy

Effective November 3, 2026

The short version

  • Continuity's publisher runs no servers and collects no data. There is no telemetry, analytics or tracking.
  • In local mode (the default), everything stays in a file on your own machine.
  • In team mode, coordination data goes only to a server that you or your team deploy and control.
  • Continuity stores file paths, never file contents.

Who we are

Continuity ("the plugin") is an open-source plugin and MCP server for Claude Code, published by Uzair Hayat ("we", "us"). Its source code is public at github.com/uziiuzair/continuity-mcp, so anything described here can be checked against the code. This policy covers the plugin and this website.

Data we collect

None. We don't operate a backend for Continuity, and the plugin never sends anything to us. It contains no telemetry, crash reporting, analytics or advertising code. We cannot see your sessions, your code or anything the plugin stores.

What the plugin processes on your behalf

To coordinate parallel sessions, the plugin records the following activity. Where it is stored depends on the mode you choose (see below).

  • Session presence: a session ID and label, a hash of the working directory, the git repository name, branch and worktree path, status (active, idle, gone) and timestamps. In local mode the label includes your operating-system username.
  • Current focus: the text of the prompt you submit is saved as your session's current focus, so other sessions can see what you are working on.
  • File activity: the paths of files you edit, the tool used and when. File contents are never read for this or stored.
  • Coordination records: decisions, task claims (repository and issue number), handoffs, and messages between sessions, including the text you or your agents write in them.
  • Audit log: an append-only record of coordination events, such as check-ins, check-outs and claims.
  • Configuration: the plugin options you set. Your team API key, if any, is stored by Claude Code in your system keychain, not in plain-text settings.

Local mode (default)

With no team server configured, all of the above is stored in a SQLite database on your machine (by default ~/.continuity/continuity.db), plus small per-session state files in Claude Code's plugin data folder. Nothing is transmitted over the network.

Team mode

If you set a team API URL and key, the plugin sends the data listed above to that server so your teammates' sessions can see it. That server is a Cloudflare Worker and Postgres database that you or your organization deploy and operate. We have no access to it. Its operator, and the teammates who use it, can see the coordination data it holds. The server stores API keys only as one-way hashes.

A team server can optionally be configured by its operator to use these third-party services. None of them are enabled by default:

  • GitHub: to sync task claims with GitHub Projects and read a planning document from your repository, using a GitHub App you install.
  • Anthropic API: for an optional "plan check", which sends a proposed task description and your repository's planning document to Claude for a verdict.
  • Slack: to post escalations and a weekly digest to a webhook you provide.

When enabled, data sent to these services is governed by their own privacy policies and by your agreements with them.

Retention and deletion

The plugin cleans up some data automatically: inactive sessions are marked as ended, old file activity is pruned, and expired task claims and messages lapse. Decisions and the audit log are append-only and are kept until you delete them.

You are in control of all stored data:

  • Local mode: delete ~/.continuity/continuity.db, or uninstall the plugin.
  • Team mode: retention is decided by whoever operates your team server. Contact them to access or delete data.
  • Use the repoAllowlist option to limit Continuity to the repositories you choose.

Sharing and selling

We don't sell, rent or share personal data, because we never receive any.

This website

This site is a static page served by Cloudflare. It sets no cookies and runs no analytics or third-party scripts. As our hosting provider, Cloudflare processes standard request information, such as IP addresses, to deliver and secure the site, under Cloudflare's privacy policy.

Children

Continuity is a developer tool and is not directed at children under 18.
